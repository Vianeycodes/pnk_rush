# PNK_RUSH

Creator profile for brands: automotive lifestyle, car care and upgrades, starring a pink 2022 Chevrolet Camaro.

- Instagram: [@pnk_rush](https://www.instagram.com/pnk_rush/)
- Collabs: pnkrush.collabs@gmail.com

## What's here

A single-page site (`index.html`) with the hero video and clips in `media/`. Open `index.html` in a browser, or host the folder on any static host.

## Updating your numbers

Open `index.html`, find `const PROFILE` near the top of the script, and fill in the `value` fields. Blank values show "On request".
